# 问题分析与解决工作台

课程《AI 赋能系统化问题分析与解决》的配套 Web 工具。学员带着**自己定义的工作问题**走完八步：AI 负责发散、结构化和挑战，人负责取证、判断和拍板。

无注册、无登录。课题与 API Key 只存在本机浏览器。换设备靠导出文件，不靠账号。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173/`）。

```bash
npm run build    # 类型检查 + 打包
npm run preview  # 预览打包结果
```

## 怎么用

1. 打开首页，**新建课题**（自己写标题和场景，不选岗位）。
2. 到 **设置** 填写 OpenAI 兼容的 API（Base URL、模型名、Key）。未配置时仍可填结构，调用 AI 时会被拦住并引导去设置。
3. 按八步往下走。进入下一步前，该步的人工判断必须勾清单并写至少 12 字依据，不能只写「没问题」。
4. 任何一步都可以导出 **JSON / Markdown / Word / PPT**。JSON 用于换设备恢复；Word、PPT 用于课堂或汇报。

## 八步

| 步 | 名称 | 学员做什么 | AI 做什么 |
| --- | --- | --- | --- |
| 1 | 明确问题 | 上传材料、写差距陈述 | 不替人选题 |
| 2 | 分解问题 | 改问题树、打影响×可行动、勾选关键问题 | 生成可改的问题树与取证建议 |
| 3 | 设定目标 | 写指标、期限、程度 | 不生成目标 |
| 4 | 把握真因 | 判断假设、勾选入末端原因池 | 竞争性原因假设；5WHY 可选 |
| 5 | 制定对策 | 选原因、选 5W 焦点、选 SCAMPER 对策、打影响性×可行性 | 5W 提问与 SCAMPER 发散，不替人拍板 |
| 6 | 贯彻实施 | 补全 5W2H 与最小实验卡 | 生成可改的计划骨架 |
| 7 | 评价结果 | **自己填写**对照表：达成情况、新/消失现象、结果偏差 vs 执行偏差 | 不代写结论 |
| 8 | 巩固成果 | **自己填写**固化三件套、横向边界、假设对照与三问反思 | 不代写复盘 |

闸门：进入第 2 步需判断 1；进入第 3–5 步需判断 2；进入第 6–8 步需判断 3。

## 原则（不要破）

- AI 发散，人收敛。不宣布唯一真因，不替人决策。
- 事实 / 解释 / 假设分开。没有数据就写「未知」，不编造。
- 禁止把原因或对策写成：意识不足、责任心不强、沟通不到位、加强培训、加强管理。
- 实验默认两周内出信号，失败可退回。
- 导出不含 API Key。

## 技术

- Vite 7 + React 19 + TypeScript + React Router 7（BrowserRouter）

- 设置：`sansheng.settings.v1`
- 源码入口：`src/app/` 页面，`src/domain/` 八步数据，`src/ai/roles/` 各步 AI 角色
