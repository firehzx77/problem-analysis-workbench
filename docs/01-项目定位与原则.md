# 问题分析与解决工作台 — 项目定位与原则

> 来源：课程《AI 赋能系统化问题分析与解决》（讲师手册，2026/5/21）  
> 性质：课程衍生工具，不是另一门课，也不是通用聊天机器人。  
> 形态已确认：无账号 Web 应用；模型 API 由学员在设置中自配；闸门全部学员自检；选题由学员自定义，不预设岗位。

## 1. 一句话定义

把课堂里的**八步系统化解题流程**，做成学员能带着**真实工作课题**走完的 AI 辅导工作台：AI 负责发散、结构化与挑战，人负责取证、判断与拍板。

## 2. 为什么做这个工具

课程已经讲清了方法，但学员课后最容易掉回三件事：

1. **跳步**：看到现象就给方案，跳过事实化、结构化和验证。
2. **把 AI 当答案机**：一次提问就要根因和对策，结果是流畅的猜测。
3. **方法留在教室**：提示词散落在 PPT 里，没有课题档案，无法复盘、无法横向展开。

本工具要解决的不是“再教一遍 8D / A3 / KT / 六西格玛”，而是把这些方法背后共通的思维过程，变成**可重复执行的工作流**。

## 3. 目标用户

一期只服务**打开网页就能用的学员**，不区分岗位，也不做讲师端。

| 角色 | 使用场景 | 成功标准 |
| --- | --- | --- |
| 课程学员 | 用自己定义的真实工作问题走完八步 | 产出标准问题陈述、证据清单、可验证实验，而不是一篇感想 |
| 课后继续用的学员 | 把日报、投诉、异常、会议纪要丢进问题雷达 | 能在 2 周内设计出可停止的小实验 |

非目标（一期）：需要注册登录的账号体系；讲师班级看板；按岗位预置课题模板；一键出报告。

## 4. 产品要做成什么，不要做成什么

**要做成**

- 一条有闸门的课题流水线：扫描 → 定义 → 分解 → 目标 → 真因 → 对策 → 实验 → 复盘
- 七个可切换的 AI 角色，每个角色只做本步该做的事
- 强制区分**事实 / 解释 / 假设**，信息不足时先列缺口，不编造数据
- 每份课题都沉淀为可导出的档案（陈述、树、证据、实验卡、复盘）

**不要做成**

- 包装一层的通用 ChatGPT
- 自动给出“唯一根因”或替人做最终决策
- 只有提示词库、没有结构化和人工判断的文档站点
- 用评分动画掩盖证据不足

## 5. 不可妥协的产品原则

1. **AI 发散，人收敛。** AI 扩展可能性、攻击方案、设计实验；取舍、拍板、现场取证由人完成。
2. **先事实化，再解释，最后假设。** 评价性语言必须改写成可观察的差距；未知标为未知；假设必须带验证动作。
3. **先结构化，再追深。** 复杂问题先问题树 / 原因树，再对关键分支做 5WHY；禁止一条路径追到“意识不足”。
4. **三道闸门由学员自检，默认不可默默跳过。** Gate 1 问题是否数据化、对象化、边界化；Gate 2 优先原因是否同时有支持证据、反证检查、验证动作；Gate 3 风险是否可接受、关键假设能否先验证。通过时必须写下判断依据，系统不代为解锁，也不设讲师审批。
5. **不编造事实与数据。** 信息不足时最多提有限澄清问题，并输出待补数据清单。
6. **小实验优于完美方案。** 优先 2 周内能出信号、失败可恢复的动作；实施率比方案完整度更重要。
7. **产出必须可沉淀。** 每次走完至少留下：标准问题陈述、证据状态、被证实 / 被推翻的假设、可迁移经验。

## 6. 课程方法如何进入产品

课程并列介绍了 8D、A3、KT、六西格玛 DMAIC，但课堂真正要学员掌握的是它们共用的思维切换：

| 思维 | 在流程中的位置 | 产品里怎么落地 |
| --- | --- | --- |
| 数据思维 | 证明问题存在、验证假设 | 差距陈述、指标口径、证据状态标记 |
| 流程思维 | 问题结构不清时先拆 | IPO / 流程步骤作为问题树切分维度 |
| 优先性思维 | 资源有限时选题、选因、选方案 | 影响度 × 可行动性；4E；加权矩阵 |
| 原因思维 | 查找可控制的机制 | 竞争性假设 + 5WHY 带证据 + 停止条件 |
| 创新方案思维 | 对策创造 | 5W 选焦点 × SCAMPER 变换 |
| 风险思维 | 决策前与实施中 | 红队 / Pre-mortem；护栏指标 |

经典工具不作为一期主界面，而作为**同一课题的导出视图**（二期）：一份课题可以分别看成 A3、8D 或 DMAIC 项目卡。

## 7. 成功长什么样

学员用本工具完成一个真实课题后，应能拿出下面这组东西，而不是一份“AI 写的分析报告”：

- 一句有范围、指标、基准、现状、对象、影响、期限的问题陈述
- 一张标了事实 / 未知 / 假设的证据表
- 3 个以内的优先焦点，每个都有影响 × 行动评分
- 至少 1 条可控制、可验证的机制原因（或明确走“行动试验”路线的理由）
- 1 张最小实验卡：假设、范围、指标、成功 / 停止 / 扩大标准
- 1 次对照“问题—原因假设—方案假设—行动—结果”的复盘

课题从哪来、属于什么岗位，一律由学员自己写清；产品不预置岗位包，也不替学员选题。
