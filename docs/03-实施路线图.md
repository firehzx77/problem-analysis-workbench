# 三生 · AI 赋能问题分析解决 — 实施路线图

## 1. 建设原则

先做出**打开网页、自配 API、自己选题就能把课题走完**的闭环。一期不做账号，也不做讲师端。

宁可步骤完整、AI 能力克制，也不要聊天很强、闸门形同虚设。

## 2. 三期划分

### 第 0 期｜规划对齐（已完成决策）

五项已拍板，见文末「已确认决策」。可以按此开工。

### 第 1 期｜个人课题工作台（MVP）

**目标**：学员打开网页、在设置里填好自己的 API、用自己定义的选题，独立走完一份课题并导出。

必须交付：

1. 无账号 Web：课题本地创建 / 列表 / 导入导出；设置页配置 API
2. 八步导航（可回看，闸门须自检写依据后才能进入下一步）
3. 七个 AI 角色按步骤出现；未配 API 时结构可填、AI 调用被拦截
4. 事实 / 解释 / 假设标记，以及待补数据清单
5. 学员自定选题卡、标准问题陈述、焦点矩阵
6. 问题树 + 原因假设表 + 5WHY（带证据）
7. 5W × SCAMPER 与红队评估
8. 最小实验卡、结果对照、复盘与 Markdown / PDF 导出

技术形态：Web 前端为主；课题与 API 配置存在浏览器本地；对话只作为步骤内的辅输入。调用走学员配置的 OpenAI 兼容接口。提示词与课程手册保持同一套角色定义。

**验收方式（不按岗位验收）**

- 用任意自定选题从扫描走到复盘（可用课程里的例子当走查脚本，但不做成岗位包）
- 未配 API 时不能静默失败，必须把人带到设置页
- 闸门空过（不写依据）不能进入下一步
- 换浏览器后能靠导出文件恢复课题

### 第 2 期｜方法视图与携带性

- 同一课题导出为 A3 / 8D / DMAIC 视图
- 练习页任务化（工作扫描表、鱼骨、3×3×3）
- 课题文件分享（仍无账号；用导出包）
- 设置页支持多套模型配置切换

### 第 3 期｜组织沉淀

- 案例库：按行业、流程、问题类型检索
- 被验证的机制进入检查表 / SOP 草稿
- 横向展开向导：适用边界、不可照搬条件
- 与企业已有改善系统对接（可选）

## 3. 第 1 期建议工作切片

| 切片 | 内容 | 依赖 |
| --- | --- | --- |
| 1. 骨架与设置 | 无账号课题 CRUD、本地存储、导入导出、设置页（API）、八步状态机、闸门自检记录 | 无 |
| 2. 定义链路 | 问题雷达、定义教练、BAIDU、自定选题卡、Gate 1 自检 | 切片 1 |

## 4. 衡量指标

**学习与使用**

- 创建课题后走到 Gate 1 的比例
- 通过 Gate 1 后走到实验卡的比例（一期核心漏斗）
- 平均每题被闸门退回次数（过高说明引导差，过低说明闸门没生效）

**质量（导出档案自检 / 抽看）**

- 问题陈述是否可验证
- 是否出现被禁止的根因套话
- 实验是否可在 2 周内出信号
- 复盘是否写出被推翻的假设（而不只是“做得不错”）
- 闸门记录里是否有真实依据，而不是空白或“没问题”

不把“AI 回复字数、会话轮次、生成速度”当成成功指标。不统计登录人数（没有账号）。

## 5. 风险与对策

| 风险 | 为什么会出现 | 对策 |
| --- | --- | --- |
| 学员把它当问答框 | 界面仍像聊天 | 每步先填结构，再允许对话；角色切换可见 |
| AI 编造原因和数据 | 模型补全惯性 | 角色禁令 + 证据栏空则不准写结论 + 置信度 |
| 闸门变成点一下就过 | 没有讲师拦，学员想赶进度 | 通过必须写判断依据；依据为空不能过；清单项未勾完不能过 |
| 范围膨胀成六西格玛套件 | 课程里有 DMAIC / 统计工具 | 一期只保留思维引导，统计检验不做引擎 |
| 提示词与课程脱节 | 产品迭代后角色漂移 | 提示词入库，对照讲师手册版本号 |
| 浏览器直连 API 失败 | CORS 或网关限制 | 设置页写清兼容协议；必要时加本机/同源薄代理，Key 仍不落服务器库 |
| 换设备或清缓存丢课题 | 无账号、数据在本地 | 导出入口始终可见；关闭前未导出可提醒 |
| Key 泄露 | 配置存在浏览器 | Key 不明文展示；不写入导出的课题文件；不打进日志 |

## 6. 已确认决策

| 项 | 结论 |
| --- | --- |
| 交付形态 | 做 Web 端 |
| 模型 | 设置页由学员自己配置 API（提供商 / Base URL / 模型 / Key） |
| 账号 | 不需要注册，打开即用 |
| 闸门 | 三道闸门全部学员自检，不设讲师解锁 |
| 选题 | 不涉及岗位；选题由学员自己定义 |

## 7. 推荐仓库结构（实现时）

```
docs/                     规划与课程映射（已建）
src/app/                  八步页面、课题列表、设置页
src/domain/case/          课题、闸门自检、证据、实验的领域模型
src/ai/roles/             七个角色的系统提示词与输入输出 schema
src/ai/client/            读取本地设置、调用学员 API
src/storage/              本地课题与设置的读写、导入导出
```

课程 PPT 继续作为方法源，不直接当产品需求；产品需求以本目录文档为准，冲突时先改规划，再改提示词。
